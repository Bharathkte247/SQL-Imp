## AutoQRA wireframe (local)

The interactive wireframe lives on branch **`cursor/autoqra-feature-wireframe-a131`** (not on `main` yet).

```bash
git fetch origin
git checkout cursor/autoqra-feature-wireframe-a131
cd autoqra-wireframe
python3 -m http.server 8765
```

Then open **http://127.0.0.1:8765/** in your browser.

Or from `autoqra-wireframe/`:

```bash
./start.sh
```

See [`autoqra-wireframe/README.md`](autoqra-wireframe/README.md) for screens and details.
